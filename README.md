PhonePe Pulse – Transaction & User Analytics

Project Overview

This project analyzes PhonePe transaction and registered user data using Power BI.

Key Dashboard Features

- Total Transaction Value
- Total Transactions
- Total Registered Users
- Registered Users by Year
- Transaction Distribution by Type
- Total Transaction Value by Year
- Year-wise Transaction Analysis
- Quarter-wise Transaction Analysis
- State-wise Transaction Analysis

Tools Used

- Microsoft Power BI
- Data Analytics
- Data Visualization

Project Objective

To analyze digital payment trends, understand transaction patterns, and visualize user growth across different years and states.
